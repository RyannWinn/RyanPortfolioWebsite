# Ryan Nguyen - Personal Portfolio Website

A clean, responsive personal portfolio website showcasing my work, skills, media channels, and contact information.

## 🚀 Features

- **Responsive Design:** Optimized for desktops, tablets, and mobile devices.
- **Media & Channels Showcase:** Highlights managed video and social media channels (YouTube, Instagram).
- **Skills & About Section:** Overview of professional background and technical/creative capabilities.
- **Contact Form:** Easy way for visitors and clients to reach out.

## 🛠️ Built With

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styles, grid layouts, and animations.
- **JavaScript:** Interactive elements and smooth navigation.
